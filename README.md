## 🎯 Key Features

### 📝 Storyboard Prompts
Organize your video scenes with easy-to-use storyboard prompts. Add descriptions, adjust timing, and arrange shots in sequence.

Define the start and end frames for smooth transitions. The tool automatically interpolates between keyframes for fluid motion.

## 📖 How to Use

### Step 1: Launch the Application
After downloading, double-click the application icon to start. The main window will display your timeline editor.

### Step 2: Create a New Project
Click "New Project" and give it a name. Set your desired output resolution and frame rate.

### Step 3: Add Scenes
Use the "Add Scene" button to insert new shots into your timeline. Each scene can contain its own prompt, keyframes, and references.

### Step 4: Configure Settings
For each scene:
- Enter your text prompt describing what you want to generate.
- Upload reference images or videos.
- Set first and last keyframe positions.
- Adjust audio settings if using sound.

### Step 5: Preview & Generate
Click "Preview" to see a live sample of your video. Make adjustments as needed, then click "Generate Full" to produce the final output.

## 🔧 Troubleshooting

### Common Issues

**Application won't start:**
- Ensure ComfyUI is installed and running.
- Check that your system meets minimum requirements.
- Try running as administrator (right-click, "Run as administrator").

**Video generation fails:**
- Verify internet connection (required for model access).
- Reduce video length or resolution.
- Close other resource-heavy applications.

**Timeline not responding:**
- Restart the application.
- Clear temporary files in the app's data folder.

## 💡 Tips for Best Results

- Use clear, descriptive prompts for better video outputs.
- Start with shorter videos (10-15 seconds) to test settings.
- Experiment with different keyframe combinations for unique transitions.
- Keep audio files under 30 MB for optimal performance.
- Save your project frequently using Ctrl+S.
